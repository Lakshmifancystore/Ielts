IELTS READING PRACTICE HUB
==========================

FILES
- index.html   Main website page
- style.css    Layout and responsive styling
- script.js    Original passages, questions, timer, navigation and scoring

HOW TO TEST
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. Click "Start full test".
4. Answer the 37 questions and submit to see the results.

HOW TO UPLOAD
Upload index.html, style.css and script.js into the same folder on your existing web hosting.
If your hosting has a public_html folder, place the files there (or in a subfolder).
Open your domain or the subfolder URL to view the practice test.

IMPORTANT
- This is a front-end practice prototype. Scores are calculated in the browser and are not stored in a server database.
- The test contains original IELTS-style practice content, not copied IELTS Ace questions.
- The raw score is not an official IELTS band score.
- Internet access is only needed to load the optional Google Fonts; the test itself works without them.
